# Shard Riverside Offers

The public special offers page for The Shard Riverside Inn, linked from posters and QR codes. One static page, no database.

This repo is **public**: never put keys, prices still under discussion or anything private in it. Keep the page in the house style (Shard Riverside brand kit: river `#1A5A78`, paper `#FBF8F2`, Cormorant Garamond and Source Serif 4, "Est. 1766").
